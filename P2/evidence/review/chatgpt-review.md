- 两个 Checkoff、七个 Write-up（包含已约定执行的三个原选做项）和完整 lscpu 输出全部覆盖，保持原题顺序。

- 1656 个全数组 qsort 对照的计数可从测试循环推出；m/f 的 78 个用例覆盖完整 uint32_t 值域中的代表性边界和随机值，不表示穷尽所有输入组合。

审核容器的 LeakSanitizer 最初因 `/proc`/ptrace 限制返回环境错误；显式设置 `ASAN_OPTIONS=detect_leaks=0` 后完成上述正确性复核。因此本次新增检查不构成独立零泄漏验证；原机 Memcheck 的 0 errors / 0 bytes at exit 已作为交付证据审阅。审核容器 GCC 检查也不等同于原机 Clang 性能复现。
