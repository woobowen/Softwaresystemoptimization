## 计时与身份

内核成绩和主调优成本都采用 `CLOCK_MONOTONIC_RAW`。内核必须与同次目标进程的 RAW 原始整数时钟差做 0.005 秒容差的边界检查。已有 `process_wall_s` 与 `driver_wall_s` 继续表示 MONOTONIC；RAW 进程/driver 成本单独由原始 ns 差获得，不能通过乘钟比改写旧字段。总资源仍是每个任务 MONOTONIC、RAW、REALTIME 正差最大值，520 调用和 57600 秒硬上限不变。

完整时钟守卫采用 schema 2、`complete_raw_realtime_target_and_driver`：目标进程与完整 driver 分别比较 RAW/REALTIME 的 first/previous，比率变化门仍为 2%，逐来源、同 boot 检查。时钟历史只来自精确声明的 296 行前缀和允许的新目标记录；旧失败预热不更新基准，不能删除 first 或重新选择低成绩时段。新记录的调用覆盖字段必须严格为布尔 True，缺失、非布尔值、未知成本或不完整时钟检查不能提供有效成绩或 KEEP。已完成的两个 RAW 数值进程仅提供数值/时钟证据，由 `numeric_clock_baselines.json` 的实际 SHA 锁定，不加入参照或搜索。

RAW–QPC 两项相对区间核对支持这项有限适配的评估，不说明 RAW 或 QPC 是绝对真值，也不说明 REALTIME 在所有工作负载中稳定。旧短工作 RAW/REALTIME 变化反例与同配置波动全部保留。计时适配不能消除调度、资源竞争或配置与时段的交互。

## 分辨描述：先定计算规则，再看新 A/A

令 `P_F`、`P_M` 为八项 RAW A/A 各档两个预定配对的最大绝对相对差：

`P_tier = max_i(100*abs(B_i/A_i-1))`。

完整 A/A 后按唯一预定规则设置新的有限描述：

`rho = ceil(max(24.351654209127904, P_F, P_M))`。

常数来自已保存的新增交错 A/A 最大配对差，见旧协议的 `additional_AA_max_pair_pct` 和匹配版本的 `results/clock_followup_summary_v2/summary.json`。旧 MONOTONIC 数字只用于保留已经观察到的环境波动作为保守诊断描述，**不与 RAW 正式样本合并，不转换成 RAW 成绩**。即使新八次看起来更平稳，也不能因此删去这个已知波动。原协议的 rho=14 仍归原协议，不回写。

新的 rho 不是误差上界、置信区间、总体假阳性率或未来稳定性保证。若八次 A/A 不完整、时钟/成本不完整或粗排序门未过，不能计算出一个有利 rho 后放行；应保持正式分支受阻。rho 仅用于完整观测表/面板的有限敏感性描述，不放宽 2pp 质量风险或 5% 近优目标。`different_identity_risk_supported=false` 继续实际阻止不同返回配置身份的主实验/留出配对成为 KEEP；相关质量增益只做描述。

完整参照是三个新随机完整轮次，20 配置各三个新有效 RAW 样本；轮次种子 505063、505064、505065，原定每轮位置 0、10、20 插入 s128/O2 锚点，连同一次预热上界 70 调用。参照身份/数据目录必须是新的 RAW 批次，不能拿旧 MONOTONIC 表补格。四级 O0/O1/O2/O3 仍有独立配置身份，汇编相同也不省略。

主实验六个 seed 固定为 `700001, 804730, 909459, 1014188, 1118917, 1223646`，R=8、每次评估重复数 1。Grid 保留固定原枚举，Random 保留无放回随机访问，Greedy 保留默认随机起点与合法提前停止；S3 仅为同 Random 前缀的 6 探索 + 两个候选各 1 次复核，只有成功复核的候选可返回，评分采用该候选两个观测中位数。没有分层、patience、特殊起点或重启增强。

六块算法顺序逐项复用原协议：

1. recheck / grid / greedy / random
2. random / recheck / greedy / grid
3. recheck / greedy / random / grid
4. greedy / random / grid / recheck
5. grid / random / recheck / greedy
6. grid / recheck / random / greedy

只使用各次在线搜索当时实际取得的观测；参照、锚点、别的算法和共同面板不能反馈给搜索。每块相关搜索全部结束、返回冻结后才形成去重共同面板，配置集合为全部返回与参照最优的并集，三轮新独立交错确认；同一配置的外部确认只计一次实际项目成本。相同配置在统一参照/共同面板中获得相同质量映射，另保留独立 A/A 数据检验真实波动。历史曲线不能用最终确认回填，S3 探索与复核后的返回资格变化仍分别标记。

## 保留与确认规则

原接受规则的数值均保留：近优目标 5%，质量风险 2pp，严重回归 10pp；质量路径中位收益下界 2pp、至少两块下界 5pp、调优成本增幅上限 10%；效率路径为支持风险下界且配对主 driver 成本中位降低至少 10%。主成本在新协议明确选 RAW；MONOTONIC 调优成本作为单独观测保留，不能择优混用。有限实验不给无负优化保证。

由于不同身份的精细风险不受支持，本环境的可保留路径限定为每个相关有效配对内 Random 与 S3 返回身份相同、质量差严格为 0、成本和外部面板完整、RAW 调优成本满足原 10% 效率门，并且三个新留出种子再符合原规则。不同 seed 可以返回不同配置；任何配对内身份不同仍为 INCONCLUSIVE。质量路径仅作描述，不授予 KEEP。
